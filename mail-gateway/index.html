🔑 Change the keys

Three keys protect the gateway. The full key can draft and send, and belongs only on this page. The draft-only key is for PDF Studio and every other tool: it can create drafts but can never send. The website key is for the website’s own forms (the After an Accident report): it can only email the agency itself.

  1. Full key
    Draft-only key
    Website key
  2. In Google Apps Script open BLI Mail Gateway, click the gear icon, then Script properties. Paste the full key into GATEWAY_SECRET. Add a property named GATEWAY_DRAFT_SECRET and paste the draft-only key. Add a property named GATEWAY_AGENCY_SECRET and paste the website key. Click Save script properties.
  4. Hand out the other two keys:
    The draft-only key goes into every other tool’s gateway settings. The website key goes into Cloudflare: copy it, then run SET-WEBSITE-MAIL-KEY.cmd and paste it there.
