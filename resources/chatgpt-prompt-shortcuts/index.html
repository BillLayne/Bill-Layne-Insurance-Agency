What can I copy and try?

Four worked prompt templates written for this guide. Replace the bracketed details with your task. These are illustrative starting points; results vary with the model and context.

/truthmode · Prompt example

How can I get more useful feedback?

For a draft, plan, or webpage you want to improve.

Read the prompt
Review the draft below. Separate confirmed facts, assumptions, and open questions. Identify three strengths and the three most useful improvements. Explain your reasoning and say when there is not enough information. Do not invent evidence.

Draft: [Paste your draft here.]
/tldr · Prompt example

How can I make a long message clearer?

Turn an everyday message into a short action list.

Read the prompt
Summarize the message below in three bullets: what it says, what I need to do, and any stated deadline. Preserve names, dates, and amounts exactly. If a deadline is missing, say "No deadline stated."

Message: [Paste a message with private details removed.]
/email · Prompt example

How can I write a helpful follow-up?

Ask for an update without adding facts or promises.

Read the prompt
Write a friendly follow-up email under 120 words. Use only the facts below. Ask one clear question about the next step. Do not invent a deadline, prior conversation, price, or promise.

Recipient: [Name]
Facts: [Known facts]
Question: [What you need to know]
/checklist · Prompt example

How can I turn a task into a checklist?

Break an everyday project into manageable steps.

Read the prompt
Turn the task below into a short checklist in a sensible order. Group it into preparation, action, and follow-up. Flag missing information instead of guessing. Keep each step specific and practical.

Task: [Describe your task.]
Constraints: [Time, budget, or things to preserve.]
