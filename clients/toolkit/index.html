Which inventory should I use?

Use Home Inventory to document belongings before something happens. Use Claims Inventory to organize damaged or missing items after a loss. Review AI suggestions in either tool.

Does this page save my documents or policy?

No. This pilot page is a tool directory and a temporary renewal checklist, not an online document vault. Each linked tool has its own data handling. Keep copies of reports you want to retain.

Are these tools currently client-only?

The new toolkit and home-record tools use an approved email address and a temporary sign-in code to access these pages. Existing inventory and property-lookup programs remain publicly available.
